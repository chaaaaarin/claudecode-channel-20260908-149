## OpenAIアカデミーとは何か

まず前提から。**OpenAI Academy（`academy.openai.com`）は、OpenAI がタダで公開しているオンライン学習サイト**です ✅。閲覧するだけならサインインは不要で、日本からもそのまま開けます。進捗の保存と修了証の受け取りにだけ ChatGPT アカウント（無料枠で可）が要ります ✅。

トップには難度順に3つのコースが並んでいます ✅。

| コース | 対象 | 所要 | 学ぶこと |
|---|---|---|---|
| AI Foundations | AIが初めての人 | 60〜75分 | 明確な指示・文脈の足し方・出力レビュー・責任ある利用 |
| Applied AI Foundations | 少し慣れた人 | 75〜90分 | 繰り返し作業を「手順に分けて、レビューを挟む」形にする |
| Agents and Workflows | AIに任せる側の人 | 75〜90分 | エージェントに構造化された仕事を任せる（文脈・出力定義・境界・レビュー・再利用） |

3コースはいずれも**完全無料**、修了証は Gradual（グラデュアル）というサービスが発行します ✅。ただしこの修了証は「学習の修了証明」であって、OpenAI の公式資格ではない、と公式が明記しています 🔶。

エンジニア向けには、アカデミー内の**「Builders（ビルダーズ）」コミュニティ**（35,677メンバー）に、Codex を使ったエージェント開発の教材がまとまっています ✅。今回の主役はこちら側です。

**向かない場面**: アカデミーは自習型なので、AIにそもそも興味がない人・カタカナ用語で止まる人は一人だと進みにくい構成です。教材の一部は開発者向けで用語のハードルもあります 🔶。

## GPT-6 Astraでエージェントは何が変わったのか

ここが今回の軸です。**2026年9月3日、OpenAI は新モデル「GPT-6 Astra」を公開**しました ✅。前世代は「GPT-5.6 Sol（ソル）」で、元動画はこの世代の話でした。

Astra で跳ねたのは主にエージェントの実行力です ✅。

| 指標 | 内容 | Astra | GPT-5.6 Sol |
|---|---|---|---|
| コンピュータ操作の速さ | OSWorld 2.0 の遅延シミュレーション（1タスクあたりの時間） | 約40分（72.6%） | 約75分（65.7%） |
| 操作の総合速度 | Codex ハーネス更新＋モデル効率（Mind2Web） | Sol 体験比 **1.9倍速** | 基準 |
| エージェントのコーディング | Terminal-Bench 4.0 | **57.9%** | 37.3% |
| 画面上の要素指定 | ScreenSpot-Pro（ツールなし） | 92.7% | 76.9% |

数字の意味を1つだけ補足すると、たとえば「フォーム入力・CRM更新・カレンダー整理・オンライン調査と要約・サイト作成とフロントのQA」といった手作業を、**Sol 比で約47%短い時間**でこなせるようになった、というのが OSWorld の結果です ✅。

もう1つ、**長時間タスクでの「記憶」**が変わりました。これまでは会話が長くなると内容を要約圧縮（compaction）していて、失敗の理由などが抜け落ちがちでした。Astra の Codex は**ノートをコンテキストの区切りを跨いで保持**し、過去のメッセージやツール出力も検索できます（`config.toml` で有効化、数週間後に既定へ）✅。

**向かない場面・注意**: Astra はサイバー能力が OpenAI の基準で「Critical（重大）」に達しました ✅。そのため追加の安全チェックが入り、**正当な作業でも一時停止・確認要求で止まることがあります**（ChatGPT / Codex では再確認、API では停止）✅。また、書かれた推論を監視するしやすさは前世代より下がった、と OpenAI 自身が認めています 🔶。

<a id="s4"></a>
## モデルが賢くなったのに、なぜ「学ぶ」必要があるのか

「そんなに賢いなら、もう勉強しなくていいのでは？」——ここが今回いちばん伝えたいところです。答えは逆で、**賢くなったからこそ「任せ方」で差がつくようになりました**。

根拠は Astra 自身の挙動です ✅。

- **あいまいな指示**: Astra は routine な穴（命名・置き場所など）は文脈から自分で埋めますが、**結果が変わる判断のときだけ質問**します。Codex では非同期に質問しつつ、答えを待たなくてよい部分は先に進めます。無回答なら妥当な仮定で進めますが、重大な判断は待ちます ✅。
- **軌道修正（ステアリング）**: 途中の指示変更を「新しいゴール」と誤解せず、元の依頼と制約を保ったまま方向を変えます ✅。

つまり、**こちらが「どこまでが完了か」「何を渡すか」「どこで止まってほしいか」「適用前に何を見せてほしいか」を渡せているかどうか**が、そのまま成果の質になります。高性能な機械でも、渡す図面が雑なら出てくる物も雑、というのに近い関係です。

この「渡し方」を体系化したのが、次の4つの型です。

## 講座で教わる4つの型

Codex Bootcamp 101 で明示的に教わるのは、次の4つです ✅。1つずつ、何を渡すかで書きます。

1. **切り出し（scoping）** — 「どこまでできたら完了か」を1文で決め、**今回は触らない範囲**も明記する。ゴールと非スコープの両方を先に固定する。
2. **文脈（context）** — 対象のファイル／関数、再現手順や失敗テスト、期待する挙動（正常系・異常系）、関連ドキュメントや過去のPR、制約（禁止ライブラリ・命名規則・依存追加の可否）を渡す。
3. **軌道修正（steering）** — 進行中に方向を直す前提で、「不明点が出たらどう振る舞うか」を先に決めておく。止まって全部聞く／非同期で聞きつつ安全な範囲は進める／安全側の仮定で進めて重大判断だけ確認、の3択。
4. **適用前レビュー（review）** — 変更をいきなり全適用させず、差分の要約・テスト結果・変更理由・影響範囲を先に見せてもらい、受け入れ条件（完了の判定）を決めておく。

201 ではこれをチームの共有設定（リポジトリ指針・承認・サンドボックス・再利用スキル）に、301 では本番自動化（権限・サブエージェント・Codex SDK・CI）に広げます ✅。

**この動画で配るキットから、依頼文の実例を1つだけ載せておきます**（残りはプレゼントで）。これは3つ目の「軌道修正」を毎回書かずに済ませるため、`AGENTS.md`（エージェンツ・エムディー）に一度貼っておくものです。

```text
## 不明点が出たときの進め方
- 結果が変わらない細かい前提（命名、置き場所、書式など）は、このリポジトリの慣習に合わせて
  自分で埋めて進めてください。埋めた前提は作業ログに1行残してください。
- 判断で結果が変わる場合は、質問を投げたうえで、その回答を待たなくても進められる部分は
  先に進めてください（非同期で質問する）。
- 次のものは「後戻りできない判断」です。私の明示的なOKが出るまで実行しないでください:
  <例: 本番データベースへの書き込み / 課金が発生する操作 / 外部への通知・投稿 /
  依存パッケージの追加・削除 / 100行を超える一括変更>
- 30分待っても回答が無いときは、安全側（変更を最小にする側）の仮定で進め、危険な操作の
  手前で止まって待ってください。
```

## 料金・修了証・Claude Codeユーザーでも意味があるか

**料金**: コース・ブートキャンプとも受講は無料です ✅。受講料・サブスク・クレカは不要。閲覧はサインイン不要で、進捗保存と修了証にだけ ChatGPT アカウント（無料枠で可）が要ります ✅。Codex を実際に動かすぶんは ChatGPT の各プランや API の料金がかかります（Astra の API 標準価格は入力 $10 / 出力 $50、100万トークンあたり）✅。

**修了証**: 取れます。ただし発行元は Gradual で、公式には「These are not OpenAI Certifications（OpenAI の資格ではない）」「公式の資格を表すものではない」と明記されています 🔶。履歴書の資格欄に書くものではなく、**学習の区切り・社内共有の材料**という位置づけで見るのが正確です。

**Claude Code（クロードコード）派でも意味があるか**: あります。4つの型（切り出し・文脈・軌道修正・適用前レビュー）は、Codex でも Claude Code でも中身は同じです 🔶。教材は Codex を題材にしていますが、**依頼の設計スキルとして持ち帰れます**。Claude Code をやめる話ではなく、「実装を投げる先の選択肢が1つ増えた」と捉えるのが実態に近いです。

## 注意点（ここは割り引いて聞く）

- **教材はまだ前世代の記述が残っている** 🔶: Codex の解説教材（Codex for Builders）は 2026年9月2日更新時点で「GPT-5-Codex」基準の書き方です。Astra 専用のコースはまだありません。学べるのは「型」で、**モデル名は新しいものに読み替える**必要があります。
- **Agent Builder / Evals は終了予定** ✅: OpenAI は「AgentKit の Agent Builder と Evals を、2026年11月30日で提供終了する」と公式に告知しています。ノーコードのビジュアル構築（Agent Builder）を今から学び込むのは筋が悪いです。公式の代替はコード派が「Agents SDK」、自然言語派が ChatGPT の「Workspace Agents」です。
- **安全チェックで作業が止まることがある** ✅: 前述のとおり Astra はサイバー Critical のため、正当な作業でも一時停止・確認要求が入る場面があります。
- **半年で古くなるのでは？** という疑問について: モデル名・ベンチマークの数値は変わり続けます。ただし「切り出し・文脈・軌道修正・レビュー」という設計の型は、モデルが変わっても効き続ける部分です。**数字は追わなくてよく、型だけ持っておく**、が現実的な付き合い方です 🔶。

## 動画内で補足する用語

- **OpenAI（オープンエーアイ）**: ChatGPT・Codex・GPT シリーズを作っている会社。
- **GPT-6 Astra（アストラ）**: OpenAI が2026年9月3日に公開した新モデル。コンピュータ操作・自律作業・コーディングを強化。
- **Codex（コーデックス）**: OpenAI のコード用AIエージェント。CLI・アプリ・Web・IDE・GitHub で動く。中身のモデルが GPT-5.6 から GPT-6 Astra に更新された。
- **OpenAI Academy（オープンエーアイ・アカデミー）**: OpenAI の無料オンライン学習サイト（`academy.openai.com`）。
- **Builders（ビルダーズ）**: アカデミー内の技術者向けコミュニティ。
- **Codex Bootcamp（コーデックス・ブートキャンプ）**: Builders の3部ライブ講座（101 / 201 / 301）。録画あり。
- **Agents and Workflows（エージェンツ・アンド・ワークフローズ）**: アカデミーのコースの1つ。非エンジニア向けで、エージェントへの仕事の任せ方を学ぶ。修了証あり。
- **AGENTS.md（エージェンツ・エムディー）**: Codex にプロジェクトの前提や約束事を渡す設定ファイル。Claude Code の `CLAUDE.md` に相当。
- **AgentKit（エージェントキット）／ Agent Builder（エージェント・ビルダー）**: OpenAI のエージェント構築ツール群。ビジュアル構築の Agent Builder と Evals は2026年11月30日で提供終了。
- **MCP（エムシーピー）**: AIエージェントを外部のツールやデータにつなぐ共通の仕組み。
- **scoping（スコーピング）／ steering（ステアリング）**: それぞれ「タスクの切り出し」「進行中の軌道修正」。Codex Bootcamp で使われる用語。
- **修了証（certificate）**: コースを終えると発行される学習の証明。OpenAI の公式資格ではない。
